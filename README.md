Sales and Profit Dashboard | Tableau

Project Overview

This project presents an interactive Sales and Profit Dashboard developed using Tableau. It focuses on visualizing sales performance and profitability to make data easier to understand and analyze.

Objectives

- Visualize sales and profit performance.
- Identify trends and patterns in the data.
- Present key business insights through interactive visualizations.
- Simplify data analysis using an intuitive dashboard.

Tools Used

- Tableau Public
- Data Visualization
- Data Analysis

Project File

The Tableau workbook (`Sales_and_Profit_Dashboard.twb`) is included in this repository.
